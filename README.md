# xc-ego

基于 **EgoLite（`ego-browser`）** 的 **海博中台** 与 **美团商家后台**（支持小仓 / 乐心宜等多中台）通用浏览器自动化 Skill。

## 解决什么问题

- **零门槛默认资料直连**：无需预先新建一堆固定命名的浏览器资料，直接使用 EgoLite 默认资料即可登录并操作海博中台与单个美团中台（同时支持多窗口 `taskSpace` 并行）；仅在美团侧需要同时登录两个不同中台账号时，才按需多建 1 个资料隔离会话。
- **海博中台通用自动化**：覆盖海博任意报表查询、导出与后台操作，遵循「能输入优先输入、先看现场再操作」原则，兼容业务单元切换、弹窗清理、筛选回读、操作人 + 时间锚点防重导与 `.xlsx` 结构验包。
- **美团商家后台通用操作**：覆盖闪购商家端与外卖商家版各类门店运营页面（起送价、配送费、活动报名、商品、评价、推广等），通过 `scripts/lib/meituan_controls.mjs` 核对当前单店上下文（拦截连锁「全部门店」缺少 `wmPoiId` 与隐式 Cookie 串店风险），写操作前后自动留存快照校验。
- **产出路径由用户做主**：首次产出可从推荐位置（桌面 `xc-ego产出/`、下载文件夹或自定义路径）选择保存目录并记住偏好，不再默认藏进 Skill 安装目录。
- **跨平台低门槛运行**：内嵌零依赖 Node ESM 脚本，由 EgoLite 内置运行时直接执行，无需用户本机另装 Node.js 或 Python；Windows 与 macOS 通用。
- **本机流程固化与直呼复用**：新操作跑通后，以清晰的结构化卡片询问是否固化至本机 `~/.xc-ego/workflows/`；固化时**只固路径、不写死中台/门店/渠道/日期/数值等参数**，下次直接说出表名或目标操作即可匹配复用。

## 适用范围与边界

- 仅处理 **海博中台（`zt.hiboos.com`）** 与 **美团商家后台（`shangoue.meituan.com` / `waimaie.meituan.com`）** 相关任务，不处理纯本地文件整理或其他网站操作。
- 因各用户自定义导出列设置不同，**不校验**导出列清单与列顺序；重点守住登录态、中台与业务单元、筛选回读、操作人 + 时间锚点防重导与 `.xlsx` 结构 5 项底线检查。
- 写操作（如改起送价、改配送费、报名/取消活动或海博改价、改库存）同样支持固化并由 Agent 按指令明确度自主判断执行完成；仅在缺参、存在歧义、页面状态异常或遇登录验证时停下询问。

## 安装

一键安装到当前已支持的 AI 客户端：

```bash
npx -y skills add Pikachu-pi/xc-ego -g --all
```

也可手动将本仓库中的 `skills/xc-ego` 目录复制到对应 AI 客户端的 Skills 目录：

- Antigravity / Gemini：`~/.gemini/config/skills/xc-ego`
- Claude Code：`~/.claude/skills/xc-ego`
- 通用 Agent Skills：`~/.agents/skills/xc-ego`

> 安装包内不包含空的 `产出文件/` 目录；产出默认保存至用户选定位置（优先推荐 `<桌面>/xc-ego产出/` 或 `<下载>/xc-ego产出/`，可通过 `~/.xc-ego/preferences.json` 的 `outputRoot` 持久化，不写入公共 Skill 目录）。

## 最短使用示例

安装后只要指令涉及海博或美团商家后台，AI 会自动识别并触发（无需刻意指定技能名）；例如：

> 打开海博网页（小仓中台），在左侧导航栏点击「数据」→「订单日报表」，仓店选择「章丘店」，渠道勾选「美团」，日期范围选择「11月23日~11月25日」，最后点击导出。

> 帮我查一下小仓美团闪购后台章丘店当前的起送价和配送费。

> 导出订单日报表，小仓，章丘店，美团，昨天。（命中已固化流程后可直接调用）

> 检查一下本机 EgoLite 和海博、美团的登录状态是否就绪。

## 运行依赖

- 支持 Agent Skills 的 AI 客户端（如 Antigravity、Claude Code、Codex、Cursor 等）
- 本机安装 **EgoLite（`ego-browser`）**，官网：`https://lite.ego.app/`
  - **常规使用**：直接使用 EgoLite **默认资料**登录你要用的海博、美团网址即可，无需特意建新资料。
  - **仅当美团同时用两个中台账号（如小仓 + 乐心宜）**：因为同一个资料下美团只能保持 1 个登录账号，保留默认资料登一个、新建 1 个任意名称的资料登另一个即可。
- 必须在具备 EgoLite `User Data` 读写权限的宿主机非沙箱环境中运行，执行前先通过 `ego-browser nodejs -e "await profiles()"` 探活（详见 `skills/xc-ego/references/install-egolite.md`）。

## 隐私与安全

- 本仓库仅发布运行这个 Skill 所需的说明文档与无依赖脚本，不包含任何个人路径、登录凭证、业务报表或测试数据。
- 个人环境配置与已固化的固定流程默认保存在使用者自己的 `~/.xc-ego/`（`preferences.json` 与 `workflows/`），与公共 Skill 目录隔离，升级不覆盖。
- 绝不自动固化流程或把具体日期写死进固定路径；所有写操作在缺参、目标多义或页面状态异常时停下向用户核清后再提交。
